# Spice Garden Restaurant Website

A modern, responsive restaurant website built with React and CSS.

## Features
- Responsive design for desktop and mobile
- Restaurant homepage and navigation
- Popular food menu with prices
- About and contact sections
- WhatsApp ordering link

## Technologies
- React
- JavaScript
- CSS
- Vite
- Git and GitHub

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL shown in your terminal.
